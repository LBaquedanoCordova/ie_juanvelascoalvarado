# Sistema de Tickets y Servicios en PHP y MySQL

Este sistema de Registro y Control de Notas para Estudiantes, desarrollado en PHP y MySQL, permite al usuario administrador o profesor gestionar estudiantes, registrar los años escolares o semestres (útil tanto para escuelas como universidades), ingresar y modificar las notas de distintas materias, así como calcular y validar automáticamente el promedio de calificaciones. La aplicación ofrece una interfaz responsiva y la capacidad de generar reportes en PDF.
